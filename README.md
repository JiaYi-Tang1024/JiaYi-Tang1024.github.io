# Jensen Tang - Personal Portfolio Website

Welcome to my personal portfolio website! This modern, responsive website showcases my projects, skills, and professional journey.

## 🌟 Features

- **Modern Design**: Clean, professional design with smooth animations and transitions
- **Fully Responsive**: Optimized for all devices - desktop, tablet, and mobile
- **Interactive Elements**: Smooth scrolling, typing animations, and hover effects
- **Performance Optimized**: Fast loading with efficient CSS and JavaScript
- **SEO Friendly**: Comprehensive meta tags and semantic HTML structure
- **Accessibility**: ARIA labels and keyboard navigation support

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for better structure and SEO
- **CSS3**: Modern styling with Flexbox, Grid, animations, and gradients
- **JavaScript (Vanilla)**: Interactive features without dependencies
- **Google Fonts**: Poppins font family for elegant typography

## 📱 Sections

1. **Hero**: Eye-catching introduction with animated text and floating shapes
2. **About**: Personal introduction and highlights
3. **Skills**: Showcase of technical skills and expertise with progress bars
4. **Projects**: Featured work with hover effects and tags
5. **Contact**: Contact information and functional form
6. **Footer**: Social links and copyright information

## 🚀 Getting Started

Simply open `index.html` in your web browser to view the website locally.

For development with live reload:
```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080` in your browser.

## 📂 File Structure

```
├── index.html          # Main HTML file
├── styles.css          # All CSS styles and animations
├── script.js           # JavaScript for interactivity
├── favicon.svg         # Website favicon
├── 404.html            # Custom 404 error page
├── robots.txt          # Search engine crawling instructions
├── CNAME               # Custom domain configuration
└── README.md           # This file
```

## 🎨 Customization

To customize the website for your own use:

1. **Colors**: Edit the CSS variables in `styles.css` (`:root` section)
2. **Content**: Update text in `index.html`
3. **Images**: Replace placeholder content with your own
4. **Social Links**: Update URLs in the footer section
5. **Contact Info**: Modify email and location in the contact section
